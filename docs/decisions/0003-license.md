# ADR 0003 – License

Status: accepted · 2026-09-30

## Context

The mod will be open source. The license decides whether we may copy code from other mods.

## Options

| License | Meaning |
|---|---|
| MIT | permissive, attribution only |
| GPL-3.0 | derivatives must stay GPL |
| AGPL-3.0 | like GPL, also for network use; required if we copy code from PotionsPlus (AGPL-3.0) |

Reading other mods and reimplementing is fine under any option; copying code is not.

## Decision

MIT. Code may be copied from MIT / MIT-0 / Unlicense sources (Jötunn, JotunnModStub, Server Devcommands, AzumattDev templates) with attribution. AGPL (PotionsPlus) and unlicensed mods (GreydwarfCloak, Valheim Legends) are read for their approach only and reimplemented. Decided 2026-09-30.
